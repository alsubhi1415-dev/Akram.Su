# نسخة الأمان — الإصدار 11.0

هذا المجلد نسخة كاملة من البرنامج عند الإصدار 11.0 (كوميت ea603423).

## محتوياته
- `index.html` — الملف المبني الجاهز للتشغيل (مطابق للنسخة الحية عند الإصدار 11.0).
- `fleet-database.jsx` — المصدر الكامل.

## إجراء الرجوع
1. اقرأ `backup/v11.0/index.html`.
2. ارفعه بـ PUT على `index.html` في جذر الفرع `main` مع sha الحالي للملف.
3. راقب `/pages/builds/latest` حتى تصير الحالة `built` على الكوميت الأخير.

## مبدأ حاسم
`data.json` و `ver.json` مستقلان تماماً عن نسخة البرنامج، فلا يتأثران بأي رجوع أو تقدّم في الإصدارات.
الرجوع يعيد الواجهة والمنطق فقط، والبيانات تبقى كما هي.

نسخة أمان سابقة متاحة أيضاً: الوسم `v9.8-stable` والمجلد `backup/v9.8/`.
