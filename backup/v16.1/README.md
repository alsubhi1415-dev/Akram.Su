# نسخة الأمان — الإصدار 16.1

نسخة كاملة من البرنامج عند الإصدار 16.1.

## المحتويات
- `index.html` — الملف المبني الجاهز للتشغيل (مطابق للنسخة الحية).
- `fleet-database.jsx` — المصدر الكامل.

## إجراء الرجوع
1. اقرأ `backup/v16.1/index.html`.
2. ارفعه بـ PUT على `index.html` في جذر الفرع `main` مع sha الحالي.
3. راقب `/pages/builds/latest` حتى تصير الحالة `built`.

## مبدأ حاسم
`data.json` و `ver.json` مستقلان تماماً عن نسخة البرنامج — لا يتأثران بأي رجوع أو تقدّم في الإصدارات.

نسخ أمان أخرى: `v11.9` و `v11.0` و `v9.8` بوسومها الدائمة.
